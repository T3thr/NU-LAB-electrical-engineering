# NU-LAB Electrical Engineering

ระบบสื่อการสอน คู่มือการทดลอง และห้องปฏิบัติการเสมือนจริง วิศวกรรมไฟฟ้า
ภาควิชาวิศวกรรมไฟฟ้าและคอมพิวเตอร์ คณะวิศวกรรมศาสตร์ มหาวิทยาลัยนเรศวร

คลังข้อมูลรหัสต้นฉบับ: https://github.com/T3thr/NU-LAB-electrical-engineering

## วัตถุประสงค์ของโครงการ

โครงการนี้พัฒนาขึ้นเพื่อให้คณาจารย์และนิสิตสามารถเข้าถึงเอกสารคู่มือปฏิบัติการ การวิเคราะห์รูปคลื่นสัญญาณจริง และการฝึกปฏิบัติการบนโต๊ะทดลองเสมือนจริง (Virtual Laboratory Workbench) ได้อย่างสะดวก รวดเร็ว และทำงานได้แบบออฟไลน์ 100% โดยไม่ต้องติดตั้งโปรแกรมเสริม

## จุดเด่นของระบบ

1. **สถาปัตยกรรมออฟไลน์สมบูรณ์ (Offline-First)**:
   ไฟล์ทั้งหมดเป็น Pure HTML, CSS และ JavaScript ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ต สามารถเปิดใช้งานได้โดยตรงบนเครื่องคอมพิวเตอร์ในห้องปฏิบัติการ

2. **โต๊ะทดลองเสมือนจริงแบบจำลองลึก (Virtual Bench Simulator)**:
   - จำลอง Breadboard 830 จุด พร้อมกฎทางไฟฟ้าตามตำแหน่งจริง
   - แหล่งจ่ายไฟตรง Siglent SPD3303C ปรับแรงดันและจำกัดกระแสได้
   - มัลติมิเตอร์ HP 34401A วัด True RMS ACV, DCV, Frequency, Resistance พร้อมระบบฟิวส์
   - เครื่องกำเนิดสัญญาณ HP 33120A โหมด 50 Ohm และ Hi-Z พร้อมเมนูควบคุมเทียบเท่าเครื่องจริง
   - ออสซิลโลสโคปดิจิทัล พร้อมโหมด Softkey, Cursors (X1/X2), Auto Scale และโพรบ Probe Comp
   - ตัวประมวลผลวงจร Complex Nodal Solver ใช้วิธี Admittance Matrix แก้สมการจริง
   - โหมดมุมมอง 3 มิติ (WebGL 3D Simulator) สามารถเดินสำรวจและควบคุมเครื่องมือวัดได้

3. **รายงานวิเคราะห์ผลการทดลองจริงฉบับละเอียด (Lab 7 Analysis)**:
   รวบรวมภาพถ่ายหน้าจอออสซิลโลสโคปจริงทั้ง 10 รูป พร้อมการอ่านค่าสเกล การคำนวณเปรียบเทียบเชิงทฤษฎี และการวิเคราะห์คำถามท้ายการทดลอง

## วิธีการเปิดใช้งาน

### การใช้งานแบบ Local Offline
เปิดไฟล์ `index.html` หรือ `virtual-lab/index.html` ด้วยเว็บเบราว์เซอร์สมัยใหม่ เช่น Google Chrome, Microsoft Edge, Mozilla Firefox หรือ Apple Safari ได้ทันทีโดยไม่ต้องติดตั้งเว็บเซิร์ฟเวอร์

### การเผยแพร่ผ่าน GitHub Pages
เมื่อนำโค้ดขึ้นสู่ GitHub ทางคลังข้อมูลได้จัดเตรียม GitHub Actions Workflow ในไดเรกทอรี `.github/workflows/deploy.yml` ซึ่งจะทำการ Deploy ระบบสู่ GitHub Pages โดยอัตโนมัติ

## แหล่งอ้างอิงทางวิชาการ

- คู่มือปฏิบัติการวิศวกรรมไฟฟ้า 1 (รหัสวิชา 305141 และ 305142) ภาควิชาวิศวกรรมไฟฟ้าและคอมพิวเตอร์ คณะวิศวกรรมศาสตร์ มหาวิทยาลัยนเรศวร
- คู่มือการใช้งานเครื่องมือวัด Siglent Technologies, Keysight Technologies และ Hewlett-Packard
