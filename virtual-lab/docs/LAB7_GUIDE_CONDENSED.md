## 1. ข้อมูลพื้นฐานและรายการอุปกรณ์ (Overview & Apparatus)

### 1.1 วัตถุประสงค์ (Objectives)
1. เพื่อศึกษารูปคลื่นแรงดันตกคร่อมตัวเก็บประจุในวงจรอนุกรม RC ที่ต่อกับแหล่งจ่ายไฟสลับรูปคลื่นไซน์
2. เพื่อศึกษาความสัมพันธ์ระหว่างขนาดแรงดันและมุมเฟสที่เปลี่ยนแปลงตามค่าความจุ (C) และความถี่ (f)
3. เพื่อฝึกทักษะการใช้และการอ่านค่าจากออสซิลโลสโคป (V/DIV, TIME/DIV, Pk-Pk, Δt, φ)
4. เพื่อตรวจสอบทฤษฎีการต่อตัวเก็บประจุแบบอนุกรม

### 1.2 รายการอุปกรณ์ในโต๊ะทดลอง (Apparatus List)
- **แหล่งกำเนิดสัญญาณ (Function Generator):** HP 33120A หรือเทียบเท่า จ่ายคลื่นไซน์ 0 – 10 V_p-p (ความถี่ 50 Hz – 5 kHz)
- **ออสซิลโลสโคป (Oscilloscope):** Digital Storage Oscilloscope แบบ 2 ช่องสัญญาณ (CH1 และ CH2) พร้อมสายโพรบ
- **ตัวต้านทาน (Resistor):** ค่าคงที่ R = 1 kΩ (1,000 Ω) พิกัด 0.5 W ความเผื่อ ±5%
- **ตัวเก็บประจุ (Capacitors):** ค่า C = 0.1 µF, 1.0 µF, 2.2 µF พิกัดทนแรงดัน ≥ 50 V
- **แผงต่อวงจรและสายต่อ:** Breadboard พร้อมสายจัมเปอร์ และสายแปลง BNC to Alligator Clip

## 2. ทฤษฎีและสมการแม่บท (Theoretical Foundations)

### 2.1 วงจรอนุกรม RC และฟังก์ชันถ่ายโอน
เมื่อป้อนสัญญาณแรงดันรูปคลื่นไซน์:
```text
v_s(t) = A cos(ωt)
```
- `A` = แอมพลิจูดค่ายอด (Peak Amplitude) = 0.5 × V_p-p (ในการทดลองใช้ A = 5 V, V_p-p = 10 V)
- `ω` = ความถี่เชิงมุม = 2πf (rad/s)
- `f` = ความถี่ของสัญญาณ (Hz)

อิมพีแดนซ์รวมของวงจร:
```text
Z_C = 1 / (jωC) = -j / (ωC)
Z = R + Z_C = R - j / (ωC)
```

โดยกฎการแบ่งแรงดัน (Voltage Divider Rule) แรงดันตกคร่อมตัวเก็บประจุในรูปเฟสเซอร์:
```text
V_c(jω) = [ Z_C / (R + Z_C) ] × V_s(jω) = [ 1 / (1 + jωRC) ] × V_s(jω)
```

### 2.2 สมการคำนวณขนาดแรงดันค่ายอด (Amplitude A_c) และมุมเฟส (Phase φ)
- **ขนาดแอมพลิจูดค่ายอดตกคร่อมตัวเก็บประจุ (สมการที่ 5 ในคู่มือหน้า 57):**
  ```text
  A_c = A / √(1 + (ωRC)²)
  ```
  - ขนาดแรงดันยอดถึงยอด: `V_c(p-p) = 2 × A_c`
  - อัตราขยายแรงดัน: `|H(jω)| = A_c / A = 1 / √(1 + (ωRC)²)`

- **มุมเฟสของ v_c(t) เทียบกับ v_s(t) (สมการที่ 6 ในคู่มือหน้า 57):**
  ```text
  φ = -arctan(ωRC)   [เรเดียน หรือ องศา]
  ```
  *(หมายเหตุ: φ มีค่าติดลบเสมอ บ่งชี้ว่า v_c(t) มีเฟสล้าหลัง (Lagging) สัญญาณแหล่งจ่าย v_s(t))*

### 2.3 การวัดมุมเฟสจากหน้าจอออสซิลโลสโคป (Oscilloscope Reading)
- ช่อง CH1 (สีเหลือง): วัดแรงดันแหล่งจ่าย `v_s(t)`
- ช่อง CH2 (สีเขียว): วัดแรงดันตกคร่อมตัวเก็บประจุ `v_c(t)`
- คาบเวลาของสัญญาณ: `T = 1 / f` (วินาที)
- ช่วงต่างเวลา (Time Delay): `Δt` คือระยะห่างในแนวนอนระหว่างยอดคลื่น v_s(t) ไปยังยอดคลื่น v_c(t) ถัดไป
- **สมการคำนวณมุมเฟสจากการทดลอง (สมการที่ 7 ในคู่มือหน้า 58):**
  ```text
  φ = -(Δt / T) × 360°    [องศา]
  หรือ
  φ = -2π × f × Δt        [เรเดียน]
  ```

### 2.4 การต่อตัวเก็บประจุอนุกรม (Capacitors in Series)
เมื่อต่อ C₁ อนุกรมกับ C₂ ค่าความจุสมมูลรวม (C_eq) คือ:
```text
1 / C_eq = (1 / C₁) + (1 / C₂)  →  C_eq = (C₁ × C₂) / (C₁ + C₂)
```
- สำหรับ C₁ = 1.0 µF และ C₂ = 2.2 µF:
  ```text
  C_eq = (1.0 × 2.2) / (1.0 + 2.2) = 2.2 / 3.2 = 0.6875 µF ≈ 0.688 µF
  ```

## 3. ขั้นตอนการทดลองและตารางบันทึกผล (Procedures & Worksheets)

### ตอนที่ 7.1: ผลของขนาดตัวเก็บประจุ (C) ที่ความถี่คงที่ 300 Hz
- **พารามิเตอร์คงที่:** R = 1 kΩ, f = 300 Hz (`ω = 2π × 300 = 1884.96 rad/s`), แหล่งจ่าย A = 5.0 V (10.0 V_p-p)
- **ขั้นตอน:**
  1. ต่อวงจรอนุกรม RC ดังรูป 7.4 โดยเริ่มที่ C = 2.2 µF
  2. ต่อโพรบ CH1 วัดคร่อมแหล่งจ่าย v_s(t) และ CH2 วัดคร่อมตัวเก็บประจุ v_c(t) โดยใช้จุดกราวด์ร่วมกัน
  3. ปรับ Volts/Div และ Timebase จนเห็นคลื่น 1–2 คาบชัดเจน
  4. วัดขนาด V_p-p และหา `A_c = 0.5 × V_p-p` และวัดช่วงต่างเวลา `Δt` คำนวณหา `φ`
  5. เปลี่ยนตัวเก็บประจุเป็น C = 1.0 µF และ C = 0.1 µF ตามลำดับ

### ตอนที่ 7.3: การต่อตัวเก็บประจุแบบอนุกรม (Capacitors in Series)
- **พารามิเตอร์คงที่:** R = 1 kΩ, f = 300 Hz, C₁ = 1.0 µF ต่ออนุกรมกับ C₂ = 2.2 µF (`C_eq = 0.688 µF`), แหล่งจ่าย A = 5.0 V
- **ค่าทางทฤษฎี:**
  - `ω = 2π × 300 = 1884.96 rad/s`
  - `ωRC_eq = 1884.96 × 1000 × 0.6875 × 10⁻⁶ = 1.2959`
  - `A_c (คำนวณ) = 5 / √(1 + (1.2959)²) = 3.05 V` (แรงดันยอดถึงยอด `V_c(p-p) = 6.11 V`)
  - `φ (คำนวณ) = -arctan(1.2959) = -52.34°`
  - `Δt (คำนวณ) = (|φ| / 360°) × T = (52.34 / 360) × (1 / 300) = 0.485 ms`
