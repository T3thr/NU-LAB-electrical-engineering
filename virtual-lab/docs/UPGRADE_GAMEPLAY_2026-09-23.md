# บันทึกการอัปเกรด — 23 กันยายน 2026

## ปัญหาที่รับจากผู้ใช้

ผู้ใช้รายงานว่าเว็บใช้งานยาก สายพาดทับ UI ขาดการตอบสนองเมื่อลากหรือย้ายของ ไม่มี Undo/Redo และอยากได้การทดลองแบบเกมที่มีขั้นตอน ตรวจคำตอบจริง และเริ่มใหม่เฉพาะขั้นที่ทำผิด เอกสารนี้บันทึกการเปลี่ยนแปลงจากรุ่น 3D วันที่ 22 กันยายน โดยอิงภาพและ feedback ดังกล่าว

## การเปลี่ยนแปลงที่ใช้งานได้

### 1. แยกพื้นที่สายออกจากปุ่มเครื่องมือ

- เพิ่ม **แผงต่อสาย (patch bay)** ที่มีชื่อ GEN OUT, GEN GND, CH1 TIP, CH2 TIP และขั้วอื่นที่กำลังใช้งานอยู่ แต่ละปุ่มอ้าง terminal ID เดียวกับขั้วจริง ไม่มีวงจรจำลองอีกชุด
- หน้า 2D แสดงสายเฉพาะพื้นที่ต่อวงจร มี SVG clip ที่เว้นพื้นที่ปุ่มเพื่อไม่ให้เส้นทับหรือดักคลิก UI ของเครื่องมือ
- การเลื่อนหน้าและการเลื่อนภายในโต๊ะประกอบจะคำนวณพิกัดสายใหม่
- สายใหม่เลือกสีตามขั้ว: CH1 เหลือง, CH2 เขียว, กราวด์ดำ, แหล่งสัญญาณส้ม ผู้ใช้ยังเลือกสีเองจากส่วนการต่อสายได้
- เลือกแสดงทุกสาย / เฉพาะสายที่เลือก / ซ่อนสายได้ การซ่อนเปลี่ยนเฉพาะภาพ ไม่ได้ถอดสายจาก netlist
- แจ็คที่ต่อแล้วมีเครื่องหมายแสดงสถานะ สายยังถอดได้ด้วยดับเบิลคลิกหรือปุ่มในรายการสาย

แผงต่อสายเป็นตัวช่วยย่อระยะของสายบนหน้า 2D ไม่ใช่อุปกรณ์ไฟฟ้าที่มีอิมพีแดนซ์เพิ่มเติม ในฉาก 3D ยังเห็นสายต่อจากเครื่องมือไปยังบอร์ดตามตำแหน่งจริง

### 2. โต๊ะประกอบและการลากวาง

กด **เปิดโต๊ะประกอบ** หรือ B เพื่อขยายเบรดบอร์ด บนจอคอมขนาดกว้าง ถาดอุปกรณ์อยู่ทางซ้ายและโจทย์/ค่าที่วัดอยู่ทางขวา ทำให้หยิบอุปกรณ์และเห็นตำแหน่งปลายทางได้พร้อมกัน

- ลากอุปกรณ์จากถาดลงรูเสียบ: มีตัวอย่างอุปกรณ์ติดตามเมาส์ ขาทั้งสองและวง snap แสดงตำแหน่งก่อนปล่อย
- ลากที่ตัวอุปกรณ์เพื่อย้ายขาทั้งสองพร้อมกัน โดยคงระยะระหว่างขา
- R ระหว่างลากหมุนแนวขา 90°; เลือกอุปกรณ์แล้วกดหมุน/กลับขั้ว/ลบได้
- รูนอกขอบเขตหรือรูที่มีขาอุปกรณ์อื่นใช้แล้วจะไม่รับการวาง ไม่มีการสร้างชิ้นส่วนค้างเมื่อยกเลิก
- คลิกถาดแล้วคลิกรูสองจุดยังใช้กำหนดระยะขาเองได้ และช่องกรอกชื่อรูยังรองรับการใช้งานแบบแม่นยำหรือด้วยคีย์บอร์ด
- วางสำเร็จมีวงตอบสนองและเสียงกลไกเมื่อเปิดเสียงไว้; เคารพการตั้งค่า reduced motion
- ในภารกิจมีวงสีทองบอกตำแหน่งรูที่แนะนำ ไม่ต่อวงจรให้ผู้เล่นอัตโนมัติ

การหมุนที่ทำให้ขาออกนอกบอร์ดถูกปฏิเสธ ระบบยอมให้วางขาในบัสเดียวกันเพื่อให้เห็นผลทางไฟฟ้าและเรียนรู้ข้อผิดพลาด ตัวตรวจภารกิจจะไม่ยอมรับวงจรที่ชอร์ตองค์ประกอบ

### 3. Undo/Redo และประวัติ

- ย้อนกลับได้สูงสุด **100 คำสั่ง** ในรอบการเปิดหน้า รองรับ Ctrl/Cmd + Z, Ctrl/Cmd + Shift + Z และ Ctrl + Y
- คืนทั้งชิ้นส่วน การเชื่อมต่อ ค่ากำเนิดสัญญาณ แหล่งจ่าย มัลติมิเตอร์ ฟิวส์ ความเสียหาย สเกล/ตำแหน่งคลื่น และตำแหน่งเบรดบอร์ดบนโต๊ะ
- คืนคลื่นที่ถูกหยุดด้วย Run/Stop ได้ โดยสร้างฟังก์ชันอ่านค่าคลื่นจากฮาร์มอนิกที่บันทึกไว้
- การลากลูกบิดหรือ waveform หนึ่งครั้งนับเป็นหนึ่งคำสั่ง การหมุนล้อเมาส์ต่อเนื่องถูกรวมเป็นกลุ่ม
- การแก้ไขใหม่หลัง Undo จะยกเลิกเส้นทาง Redo เดิม
- ขณะพิมพ์ใน input, select หรือ textarea ให้เบราว์เซอร์จัดการ Undo และคีย์บอร์ดตามปกติ
- เมนู **ประวัติ** เก็บรายการล่าสุด 200 รายการ พร้อมเวลาของคำสั่งและเหตุการณ์ในวงจร ส่งออก JSON ได้

ประวัติ Undo และ log คำสั่งเป็นของรอบใช้งานปัจจุบัน ไม่ได้คงทั้ง stack ข้ามการรีเฟรช ส่วนความคืบหน้าภารกิจและ checkpoint บันทึกแยกต่างหาก ไม่มีการส่ง log ออกเครือข่าย

### 4. ฉาก 3D ที่ควบคุมได้มากขึ้น

- คลิกเครื่องมือเพื่อเปิดแผงของ **เครื่องนั้นโดยเฉพาะ** มีแท็บสลับ Supply / Meter / Generator / Scope
- เป็น DOM และ event handler ชุดเดิม จึงใช้เครื่องมือจริงในวงจรเดียวกัน
- คลิกสวิตช์เอาต์พุตบนโมเดล generator และ supply ได้; ลาก/หมุนล้อที่ลูกบิดในฉากเพื่อปรับความถี่ แรงดัน CH1 ของ supply หรือ timebase ของ scope
- ตำแหน่งขีดบนลูกบิดและไฟเอาต์พุตสะท้อนค่าปัจจุบัน
- กล้องเคลื่อนเข้าเครื่องมืออย่างนุ่มนวล การจับเมาส์หรือเริ่มขยับเองหยุดการเคลื่อนกล้องนี้ทันที; reduced motion ใช้มุมปลายทางโดยตรง
- **จัดตำแหน่งบอร์ด** แล้วลากบนโต๊ะได้สองแกนในพื้นที่ที่มีให้ สายและรูเสียบเคลื่อนตาม โดยไม่เปลี่ยนการต่อวงจร ขอบโต๊ะและตำแหน่งเครื่องมือจำกัดพื้นที่วาง
- ตำแหน่งบอร์ดเข้า Undo/Redo และจำข้ามการเปิดหน้าได้
- เลือก/ลากตัวอุปกรณ์ใน 3D ได้ มีแถบคำสั่งอุปกรณ์ที่เลือกและการเน้นขาทั้งสอง
- ฉากพักการวาดเมื่อโต๊ะประกอบครอบอยู่ เพื่อลดภาระ GPU
- จอสโคปในฉากยังวาดคลื่นสดบนมือถือเมื่อแผง 2D ถูกซ่อน โดยใช้ขนาดภาพสำรองสำหรับ texture; ทดสอบว่ามีทั้งเส้น CH1 และ CH2 จริง

### 5. เกมการทดลอง Lab 7: 3 บท / 18 ขั้น

กด **เริ่มภารกิจ** เพื่อเริ่มจากบอร์ดว่าง ในแต่ละขั้นมีเป้าหมาย จุดทดลองที่เกี่ยวข้อง รายการตรวจ และปุ่มตรวจขั้นตอน

| บท | ขั้น | สิ่งที่ผู้เล่นทำ |
| --- | --- | --- |
| 01 สร้างวงจรให้มีชีวิต | 9 | วาง R และ C, ต่อแหล่งสัญญาณและโพรบ, ตั้ง 300 Hz, จัดสเกลคลื่น, บันทึกผลของ C 2.2 / 1.0 / 0.1 µF |
| 02 สำรวจผลของความถี่ | 6 | ตั้งความถี่ 50 / 200 / 500 / 1,000 / 2,000 / 5,000 Hz และวัด A_c |
| 03 ไขปริศนาวงจรอนุกรม | 3 | ต่อ C 1.0 และ 2.2 µF อนุกรม วัดผล แล้วแก้โพรบ CH2 ที่ต่อผิดแบบภาพที่ 10 |

ตัวตรวจใช้การเชื่อมต่อของบัสและสายจริง ไม่ตัดสินจากจำนวนคลิกหรือค่าในแบบฟอร์มอย่างเดียว ตรวจแยกสายกราวด์ที่ผู้เล่นต่อจริงออกจากกราวด์ร่วมภายในเครื่องมือ จึงข้ามขั้นด้วยการละสายกราวด์ไม่ได้

การวัดต้องมีสัญญาณจริง แหล่งไซน์ ความถี่ถูกต้อง โพรบถูกจุด ไม่มีความเสียหาย และค่าที่อ่านสอดคล้องกับวงจร RC ค่าความจุ/ตัวต้านทานใช้ความเผื่อ ±10% / ±5% ตามบริบทการสอน การกรอกค่ายอดยอมรับ ±5% ของค่าที่วัดหรือ 0.025 V แล้วแต่ว่าค่าใดมากกว่า เฟสยอมรับ ±3° จากค่าที่วัด และมีการตรวจทฤษฎีแยกอีกชั้น

- ผ่านแล้วจึงกดขั้นต่อไปได้ มีสถานะสำเร็จ ภาพตอบสนอง และเสียงยืนยันเมื่อเปิดเสียง
- ทำผิดจะชี้รายการที่ยังไม่ผ่าน ผู้เล่นแก้ต่อได้ หรือกด **เริ่มขั้นนี้ใหม่** เพื่อคืน checkpoint ของขั้นนั้น โดยเก็บขั้นก่อนหน้าที่ผ่านแล้ว
- บทถัดไปปลดล็อกเมื่อผ่านบทก่อนหน้า การตรวจซ้ำไม่เพิ่มจำนวนขั้นสำเร็จซ้ำ
- เก็บความคืบหน้า สภาพวงจรปัจจุบัน checkpoint และค่าที่กรอกไว้ใน local storage; เปิดเว็บใหม่แล้วกด **เล่นต่อ**
- เก็บผลวัดทั้งหมด 11 รายการ แผนที่ภารกิจแสดงตารางความถี่ที่วัด และส่งออกรายงาน JSON พร้อมหน่วยได้
- เล่น **ทดลองอิสระ** ได้โดยไม่ต้องผ่านด่าน และใบงานเดิมยังใช้งานแยกจากบันทึกภารกิจ

เมื่อ local storage ใช้งานไม่ได้ ยังเล่น ตรวจคำตอบ และ Undo ได้ในรอบนั้น แต่จะไม่มีการจำภารกิจข้ามการเปิดหน้า

## สิ่งที่คงไว้และขอบเขต

ไม่ได้เปลี่ยนสมการ nodal AC, ค่ามาตรฐาน Lab 7, failure engine ทั้งห้า หรือเกณฑ์ในใบงานเดิม ฉากกับพื้นที่ประกอบใช้วงจรเดียวกัน ไม่มีตัวเลขสำเร็จปลอมและไม่มีเครือข่ายภายนอก เพิ่มเฉพาะ JavaScript/CSS ภายในโปรเจกต์

ฉากเป็นโมเดล WebGL แบบ procedural สำหรับการเรียนในท่านั่ง ยังไม่ใช่เกมเดินสำรวจห้อง ระบบ VR มือเสมือน หรือการชนสายแบบ rigid-body เครื่องมือบน mesh มี hot spot หลัก ส่วนการควบคุมละเอียดใช้แผงเครื่องมือที่เปิดได้ การเรียนรู้และฟิสิกส์ยังอยู่ในขอบเขต linear RC เดิม และยังไม่มีข้อมูลหลักสูตร Labs 1–6, 8–9 เพิ่มเข้ามา

## การตรวจสอบ

ใช้ Chrome ที่ติดตั้งอยู่แล้วและ Playwright สำหรับพัฒนา ตัวเว็บไม่ต้องติดตั้งอะไรเพิ่ม เปิด `index.html` จากไฟล์และใช้ออฟไลน์ได้ รายงานและภาพอยู่ใน `output/play-game/` และ `output/playwright/`

```sh
node tests/physics.test.cjs
EE_PLAYWRIGHT_PATH=/absolute/path/to/playwright node tests/play-game.test.cjs
EE_PLAYWRIGHT_PATH=/absolute/path/to/playwright node tests/interaction-edges.test.cjs
EE_PLAYWRIGHT_PATH=/absolute/path/to/playwright node tests/browser.test.cjs
EE_PLAYWRIGHT_PATH=/absolute/path/to/playwright node tests/scene.test.cjs
EE_PLAYWRIGHT_PATH=/absolute/path/to/playwright node tests/language.test.cjs
```

ใช้ action runner จาก skill `develop-web-game` เพิ่มเติม โดยปรับสำเนาชั่วคราวให้ชี้ Playwright และ Chrome ที่มีอยู่แล้ว บันทึกภาพ canvas และ `render_game_to_text()` ไว้ใน `output/play-game/skill-chrome/` ส่วนภาพเต็มหน้าของการเล่นอยู่ในชุดทดสอบหลัก การตรวจมือถือเป็น Chrome touch emulation ไม่ใช่มือถือจริง และยังไม่ใช่ผลตรวจ Safari/Firefox
