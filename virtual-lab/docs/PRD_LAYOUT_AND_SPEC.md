## โครงการ: เว็บจำลองห้องปฏิบัติการวิศวกรรมไฟฟ้าเสมือนจริง (Interactive EE Virtual Lab)

## 1. บทสรุปผู้บริหารและวิสัยทัศน์ผลิตภัณฑ์ (Product Vision)

เว็บแอปพลิเคชันนี้ถูกออกแบบมาเพื่อให้นิสิตวิศวกรรมศาสตร์ได้ฝึกปฏิบัติต่อวงจรและใช้งานเครื่องมือวัดมาตรฐานอุตสาหกรรมในสภาวะแวดล้อมที่ **"ปลอดภัยต่อการลองผิดลองถูก (Safe-to-Fail Sandbox)"** โดยมีคุณสมบัติเด่น 3 ประการ:
1. **Digital Twin เสมือนจริง:** ถอดแบบหน้าปัดและการทำงานของเครื่องมือจริงบนโต๊ะแล็บ [IMG_1226.jpeg](../part1/tools-use-in-lab/IMG_1226.jpeg) และ [10_sec7_3_fig7_16_series_c1_0_c2_2uf.jpg](../part1/lab7/result/10_sec7_3_fig7_16_series_c1_0_c2_2uf.jpg)
2. **กลไกพังจริงเมื่อต่อผิด:** นิสิตจะเห็นผลกระทบทางฟิสิกส์จริงเมื่อทำผิดพลาด เช่น ฟิวส์มัลติมิเตอร์ขาด ควันขึ้นจากตัวต้านทาน ตัวเก็บประจุระเบิด หรือการช็อตกราวด์ออสซิลโลสโคป
3. **ผสานเข้ากับเนื้อหา Lab 7 ทันที:** มีตารางบันทึกผลการทดลองตอนที่ 7.1, 7.2, 7.3 พร้อมระบบตรวจประเมินผลอัตโนมัติ

### 2.1 คอลัมน์ซ้าย (Left Column - Instrument Stack):
- กว้างประมาณ 30% ของหน้าจอ (หรือ 340px – 380px บน Desktop)
- วางซ้อนกัน 3 เครื่องในแนวตั้งจากบนลงล่างตามภาพจริง:
  1. **Siglent SPD3303C (บนสุด):** สวิตช์ Power, หน้าจอ LED แดงแสดง V/A, ลูกบิดหมุน, ขั้วแจ็คบานาน่า CH1 (+/-), CH2 (+/-), CH3 (+/-), GND
  2. **HP 34401A Multimeter (กลาง):** จอ VFD เขียว, ปุ่ม DC V, AC V, Ω 2W, Freq, ขั้วต่อ Input HI/LO, Current I (พร้อมฟิวส์ขาดได้)
  3. **HP 33120A Function Generator (ล่างสุด):** จอ VFD เขียว, ปุ่มเลือกรูปคลื่น Sine, ปรับ Freq/Ampl, ลูกบิดหมุนใหญ่, ขั้วต่อ BNC OUTPUT และ SYNC

### 2.2 คอลัมน์กลาง (Center Column - Breadboard Workbench):
- กว้างประมาณ 40% ของหน้าจอ
- เป็นพื้นที่ปฏิบัติการหลักของนิสิต:
  - **ถาดอุปกรณ์ (Component Palette):** แถวตัวต้านทาน 1 kΩ (รหัสสี น้ำตาล-ดำ-แดง-ทอง), ตัวเก็บประจุ 0.1 µF, 1.0 µF, 2.2 µF
  - **กล่องสายไฟ (Cable Dispenser):** เลือกสีสาย (แดง, ดำ, เหลือง, เขียว, น้ำเงิน) และเลือกชนิดปลายสาย (Banana-to-Banana, Banana-to-Alligator, BNC-to-Alligator)
  - **แผงต่อวงจร (Breadboard):** แสดงรูเสียบ 830 จุด พร้อมไฮไลต์โหนดที่ต่อถึงกันเมื่อนิสิตนำเมาส์ไปชี้ (Hover Snapping)
  - **สายไฟฟิสิกส์ (Interactive Wires):** วาดสายไฟด้วยเส้นโค้ง Catenary Curve หรือ Bezier Curve ที่ทิ้งตัวโค้งอย่างเป็นธรรมชาติ สามารถคลิกที่ปลายสายเพื่อย้ายรูหรือดึงออกได้
  - **Failure Canvas:** เลเยอร์โปร่งใสซ้อนทับสำหรับเรนเดอร์ควันไฟ (Smoke Particle), ประกายไฟสปาร์ก (Spark) เมื่อเกิดการต่อช็อต

### 2.3 คอลัมน์ขวา (Right Column - Digital Storage Oscilloscope):
- กว้างประมาณ 30% ของหน้าจอ (หรือ 360px – 420px บน Desktop)
- หน้าปัดออสซิลโลสโคปแบบสมบูรณ์:
  - **จอแสดงผล Canvas Scope:**
    - ตารางกริด 8×10 ช่อง มีจุดแบ่งสเกลย่อย 0.2 div
    - รูปคลื่นเรืองแสง (Phosphor Glow Effect): CH1 (เส้นสีเหลือง) และ CH2 (เส้นสีเขียว)
    - แถบสถานะบน: `1  2.00V/`, `2  2.00V/`, `1.000ms/`, `0.0s`, `Trig'd`
    - กล่อง Measurement ขวามือ: แสดงค่า `Pk-Pk(1)`, `Pk-Pk(2)`, `Freq(1)` แบบ Real-Time
  - **แผงลูกบิดและปุ่มกด:**
    - ลูกบิดหมุนปรับสเกล `V/DIV` แยก CH1 และ CH2
    - ลูกบิดหมุนปรับตำแหน่งแนวตั้ง `Position`
    - ลูกบิดหมุนปรับสเกลฐานเวลา `TIME/DIV` (100 µs – 10 ms)
    - ปุ่ม `AutoScale`, `Run/Stop`, `Single`
    - ขั้วต่อ BNC CH1 (เหลือง) และ CH2 (เขียว) พร้อมสายโพรบที่มีหัววัดและสายกราวด์ปากจระเข้

### 2.4 ลิ้นชักใบบันทึกผลด้านล่าง (Bottom Drawer / Collapsible Sheet):
- สามารถคลิกแถบด้านล่างเพื่อสไลด์เปิดขึ้นมา
- บรรจุตารางบันทึกผล 3 ตอนตามคู่มือหน้า 60, 64, 68:
  - **ตารางที่ 7.1:** บันทึกผล C = 2.2 µF, 1.0 µF, 0.1 µF (V_p-p, A_c, Δt, φ)
  - **ตารางที่ 7.2:** บันทึกผลการตอบสนองความถี่ 50 Hz ถึง 5 kHz (A_c คำนวณ vs ทดลอง)
  - **ตารางที่ 7.3:** บันทึกผลตัวเก็บประจุอนุกรม C_eq
- ปุ่ม **"ตรวจคำตอบ (Auto-Check)"** เปรียบเทียบค่าที่นิสิตอ่านได้กับค่าคำนวณทฤษฎี ให้คะแนนและข้อเสนอแนะทันที

## 3. สถาปัตยกรรมการทำงานเชิงฟิสิกส์ (Physics & Circuit Simulation Engine)

เพื่อให้เว็บโหลดเร็ว ไม่ต้องพึ่งพาเซิร์ฟเวอร์ และตอบสนองได้ 60 FPS บน Client-Side ให้ใช้ **Closed-Form State Evaluator** ดังนี้:

### 3.1 การตรวจเช็กโครงสร้างการต่อวงจร (Netlist Graph Checker)
- ระบบจะสแกนโหนดบน Breadboard และขั้วต่อเครื่องมือวัด เพื่อสร้าง Connectivity Graph:
  - ตรวจว่ามี Loop ระหว่างขั้ว HP 33120A Output ผ่าน R และ C กลับมาที่ GND หรือไม่
  - ตรวจตำแหน่งที่สายโพรบ CH1 และ CH2 จิ้มอยู่
  - ตรวจจุดที่ปากจระเข้ของโพรบหนีบอยู่

### 3.2 การคำนวณรูปคลื่นตามทฤษฎี (Waveform Generation)
หากวงจรต่อถูกต้อง (RC Series):
```javascript
const omega = 2 * Math.PI * freq;
const Zc_mag = 1 / (omega * C);
const Ac = A / Math.sqrt(1 + Math.pow(omega * R * C, 2));
const phi_rad = -Math.atan(omega * R * C); // มุมเฟสติดลบ (Lagging)
const delta_t = (-phi_rad / (2 * Math.PI)) * (1 / freq);

// ฟังก์ชันสำหรับวาดบน Canvas ออสซิลโลสโคป
function vs(t) { return A * Math.cos(omega * t); }
function vc(t) { return Ac * Math.cos(omega * t + phi_rad); }
```

### 3.3 การตรวจจับสภาวะพังจริง (Safety & Damage Evaluator)
ในทุก Animation Frame ระบบจะประเมินเงื่อนไขความเสียหาย:
1. **Scope Ground Loop Short:** หากกราวด์คลิปของ CH1 หรือ CH2 ต่อเข้ากับโหนดที่ไม่ได้ต่อกับกราวด์ของแหล่งจ่าย → เกิด Short Circuit ทันที
2. **Resistor Over-Power:** หาก `(V_rms)² / R > 0.25 W` → ตัวต้านทานเปลี่ยนเป็นสถานะ `BURNT` ค่า R กลายเป็น `Infinity` และมีแอนิเมชันควัน
3. **Electrolytic C Reverse DC:** หากต่อขั้วลบของ C เข้ากับแรงดันไฟตรง > 1.5 V จาก Siglent SPD3303C → C เข้าสู่สถานะ `EXPLODED`
4. **DMM Current Short:** หากตั้งโหมดหรือเสียบสายขั้ว Current ขนานกับแหล่งจ่าย → ฟิวส์ 3A ขาดทันที จอแสดง `FUSE OPEN`

## 4. แผนความรับผิดชอบและการรองรับ Mobile (Responsive / Mobile Adaptation)

แม้จะเป็นการออกแบบแบบ **Desktop-First** แต่เพื่อให้สามารถเปิดดูและใช้งานบนสมาร์ตโฟน/แท็บเล็ตได้:
- **บนหน้าจอ Desktop (ความกว้าง ≥ 1200px):** แสดงครบทั้ง 3 คอลัมน์พร้อมกัน
- **บนหน้าจอมือถือ (ความกว้าง < 768px):**
  - แสดงแถบ Bottom Tab Bar 3 ปุ่ม: `[Rack เครื่องมือ]`, `[Breadboard]`, `[Oscilloscope]`
  - นิสิตสามารถสลับโฟกัสไปปรับลูกบิดที่เครื่องมือ แล้วสลับมาดูบอร์ด หรือดูจอออสซิลโลสโคปขนาดใหญ่แบบเต็มจอได้
  - มีแถบสถานะด่วน (Floating HUD) ด้านบน แสดงค่าแรงดันและความถี่แบบย่อตลอดเวลา
