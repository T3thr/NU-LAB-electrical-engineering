## สิ่งที่อัปเกรด

เพิ่มฉากห้องแล็บสามมิติจริงด้วย WebGL ให้ผู้เรียนขยับมุมมองรอบโต๊ะเสมือนนั่งทดลองอยู่หน้าเครื่องมือ โดยฉากใหม่ใช้วงจร เครื่องมือ ระบบความเสียหาย และใบงานชุดเดียวกับมุมมอง 2D ไม่สร้างผลการวัดอีกชุดขึ้นมาแยกกัน

เข้าใช้งานด้วยปุ่ม **นั่งทดลองในแล็บ 3D** ด้านบนหน้าเว็บ หรือปุ่ม **แล็บ 3D** บน navbar กลับหน้าเดิมด้วย **กลับมุมมอง 2D** ระบบจำโหมดล่าสุดและตำแหน่งกล้องเมื่อเบราว์เซอร์อนุญาตให้ใช้ local storage ผู้ใช้ใหม่เริ่มที่หน้า 2D เดิมเพื่อเข้าถึงการทดลองและคู่มือได้ทันที

### 1. ห้อง โต๊ะ และเครื่องมือสามมิติ

- สร้างพื้นห้อง ผนัง โต๊ะพร้อมขา แผ่นรองต่อวงจร โคมไฟ ปลั๊ก และป้ายห้องด้วยเรขาคณิตและ Canvas ที่สร้างในเครื่อง
- เครื่องจ่ายไฟ Siglent, มัลติมิเตอร์ HP, เครื่องกำเนิดสัญญาณ HP และออสซิลโลสโคปมีตัวถัง ด้านข้าง ช่องระบายอากาศ ลูกบิด และแจ็คที่มีความลึก
- ใช้ perspective projection, depth buffer และแสงตามทิศทางผิว จึงมีการบังกันและมุมมองเปลี่ยนตามตำแหน่งกล้องจริง
- ค่าบนจอเครื่องมือและคลื่นบนออสซิลโลสโคปอ่านจากสถานะเครื่องมือเดิม แล้วอัปเดตเป็น texture ในฉาก
- ตัวต้านทานมีแถบสี ตัวเก็บประจุอิเล็กโทรไลต์มีแถบขั้วลบ ชิ้นส่วนที่ไหม้หรือแตกเปลี่ยนรูปลักษณ์ตามสถานะความเสียหาย

### 2. การขยับมุมมอง

| วิธีควบคุม | ผลที่เกิดขึ้น |
| --- | --- |
| ลากเมาส์บนพื้นที่ว่าง | หมุนมองรอบโต๊ะ |
| ลากด้วยปุ่มเมาส์ขวา หรือ Shift พร้อมลาก | เลื่อนจุดที่มองในแนวระนาบโต๊ะ |
| หมุนล้อเมาส์ | ซูมเข้าและออก |
| W / A / S / D หรือปุ่มลูกศร | เลื่อนตำแหน่งมองหน้า/ซ้าย/หลัง/ขวา ขณะ canvas มีโฟกัส |
| Q / E | หมุนมุมมองซ้าย/ขวา |
| R | กลับตำแหน่งนั่งเริ่มต้น |

จำกัดระยะซูม มุมก้มเงย มุมหมุน และขอบเขตการเลื่อน เพื่อให้กลับมาหาโต๊ะได้ง่าย การควบคุมกล้องแยกจากการหมุนลูกบิดในแผงเครื่องมือ และหยุดรับปุ่มเคลื่อนไหวเมื่อหน้าเสียโฟกัสหรือเปิด dialog

### 3. ต่อวงจรได้จากในฉาก

- คลิกแจ็ค แล้วคลิกรูเสียบบนเบรดบอร์ดเพื่อสร้างสาย
- หรือลากจากแจ็คไปยังรูเสียบโดยตรง
- ระบุรูจริงด้วย ray picking ที่แปลงพิกัดจอเป็นตำแหน่งบนระนาบเบรดบอร์ด ครอบคลุมรูเดิมทั้ง 830 จุด
- สายที่สร้างใช้ terminal ID และ netlist เดียวกับหน้า 2D จึงเปลี่ยนการเชื่อมต่อและค่าที่วัดได้จริง
- สายสามมิติวาดเป็นส่วนโค้งหย่อนจากปลายทั้งสอง และจำกัดความสูงไม่ให้ลอดใต้ผิวโต๊ะ
- ดับเบิลคลิกสายเพื่อถอดการเชื่อมต่อ
- เปิด **ดูเบรดบอร์ด** เลือกอุปกรณ์จากถาด แล้วปิดแผงเพื่อคลิกรูสองจุดในฉาก ขาแรกของ electrolytic เป็นขั้วบวก
- หากรูอยู่ชิดกัน ให้ซูมเข้า หรือใช้ช่องกรอกชื่อรูในแผง **การต่อสายและวางอุปกรณ์**

### 4. แผงเครื่องมือใช้งานจริง

แผงควบคุมด้านข้างย้าย DOM ของเครื่องมือเดิมเข้ามาแสดงชั่วคราว ไม่คัดลอกตัวควบคุมหรือทำปุ่มที่ไม่เชื่อมกับวงจร เมื่อปิดแผงหรือออกจาก 3D ระบบย้ายเครื่องมือกลับตำแหน่งเดิม จึงคง event handler ค่าเครื่องมือ สถานะ Run/Stop และข้อมูลที่กรอกไว้

เครื่องมือและเมนูด้านหลังฉากถูกตั้งเป็น `inert` ระหว่างใช้งาน 3D เพื่อไม่ให้กด Tab หลุดไปยังส่วนที่มองไม่เห็น แผงที่เปิดในฉากยังรับคีย์บอร์ดได้ตามปกติ

### 5. ใบงาน ภาษา และความเสียหาย

- เปิดและกรอกใบงานจากในฉากได้โดยไม่ออกจาก 3D
- สลับไทย / English ได้จาก navbar และหน้าต่างคู่มือกล้อง
- เปลี่ยนภาษาหรือสลับ 2D/3D โดยไม่รีเซ็ตวงจร ค่าที่วัด หรือใบงาน
- ฟิวส์ขาด ตัวต้านทานไหม้ ตัวเก็บประจุแตก กราวด์ลัดวงจร และโหมด CC ยังใช้ failure engine เดิม
- ตำแหน่งเอฟเฟกต์อิงจุดฉายในฉากหรือขั้วในแผงที่เปิดอยู่ และวัสดุของชิ้นส่วนใน 3D เปลี่ยนตามสถานะจริง

## การทำงานออฟไลน์และการกู้คืน

ไม่มี Three.js, CDN, โมเดล 3D, ฟอนต์ หรือ texture ที่ต้องดาวน์โหลด เปิด `index.html` จากไฟล์ได้เหมือนเดิม Renderer ถูกสร้างเมื่อเข้าสู่ 3D ครั้งแรกและใช้ WebGL 1 เพื่อรองรับอุปกรณ์ได้กว้างขึ้น

- จำกัด device pixel ratio ของฉากไม่เกิน 1.5 เพื่อลดภาระ GPU
- วาดด้วย `requestAnimationFrame` และพักการวาดเมื่อหน้าไม่แสดงหรือออกจาก 3D
- อัปโหลด texture ของเครื่องมือประมาณ 15 ครั้งต่อวินาที ส่วนฉาก กล้อง และรูปทรงสายวาดตามรอบหน้าจอ จอออสซิลโลสโคปต้นทางยังใช้ renderer เดิม
- เมื่อ `webglcontextlost` ระบบพักฉากและแจ้งผู้ใช้ เมื่อ context กลับมา จะสร้าง GPU resources ใหม่และวาดสถานะวงจรปัจจุบัน
- ถ้าไม่มี WebGL หรือสร้าง renderer ไม่สำเร็จ ระบบแจ้งข้อความและใช้หน้า 2D ต่อได้
- หาก local storage ถูกปิด การควบคุมและการทดลองยังใช้ได้ แต่จะไม่จำมุมมองข้ามการเปิดหน้า

## ขอบเขตของการจำลอง

มุมมองนี้เป็น **กล้องรอบโต๊ะสำหรับการทดลองในท่านั่ง** ไม่ใช่ระบบเดินสำรวจห้องแบบ FPS, VR หรือระบบร่างกาย/มือเสมือน สายเป็นเส้นโค้งสามมิติที่อิงจุดต่อจริง แต่ยังไม่มีการชนกับตัวเครื่องหรือสายเส้นอื่นแบบ rigid-body physics

ลูกบิดในโมเดลช่วยแสดงตำแหน่งและรูปทรงของเครื่องมือ การปรับค่าใช้แผงควบคุมจริงที่เปิดเมื่อคลิกตัวเครื่อง ไม่ได้กำหนด gesture แยกสำหรับลูกบิดบน mesh ทุกตัว คุณสมบัติทางไฟฟ้ายังคงเป็นแบบจำลอง linear RC ตามเอกสารเดิม

ประสิทธิภาพขึ้นกับเบราว์เซอร์ GPU ขนาดหน้าจอ และจำนวนชิ้นส่วน/สาย การวัด FPS เป็นผลจากสภาพแวดล้อมทดสอบ ไม่ใช่การรับประกันทุกอุปกรณ์

## ผลทดสอบและวิธีตรวจซ้ำ

ตรวจเมื่อ 22 กันยายน 2026 โดยเปิดไฟล์โดยตรงใน Chrome:

- การใช้งานฉาก 3D ผ่าน 16 กรณี รวมการจำลองทัชสกรีนและการกู้คืน WebGL
- การคำนวณวงจรและ state machine ผ่าน 29 กรณี และการใช้งานเว็บเดิมผ่าน 18 กรณี
- ชุดทดสอบภาษาผ่านทั้งค่าเริ่มต้นภาษาไทย การสลับและจำภาษา การคงวงจร/ใบงาน ข้อความสถานะใหม่ หน้าจอมือถือ และกรณีปิด local storage
- ฉาก 3D วัดได้ 60.00 FPS เวลาเรียกวาดเฉลี่ย 0.750 ms ต่อเฟรม และ 314 draw calls ในฉากที่ทดสอบ เวลาเรียกวาดนี้ไม่ใช่เวลา GPU ประมวลผลจนเสร็จ
- ไม่พบ JavaScript exceptions, console errors, failed requests หรือการเรียกเครือข่ายภายนอกในรอบทดสอบฉาก
- ทดสอบบน Chrome และ Chrome touch emulation ยังไม่ได้ตรวจบน Safari, Firefox หรือฮาร์ดแวร์มือถือจริง

ผลตรวจที่เป็นข้อมูลอ่านได้อยู่ใน `output/playwright/scene-verification.json` ภาพตัวอย่างประกอบได้แก่:

- `output/playwright/scene-desktop.png` — มุมมองนั่งทดลอง
- `output/playwright/scene-overhead.png` — มุมมองด้านบน
- `output/playwright/scene-scope-controls.png` — ฉากพร้อมแผงออสซิลโลสโคปจริง
- `output/playwright/scene-mobile.png` — หน้าจอสัมผัสแนวตั้ง

ใช้เครื่องมือทดสอบที่ติดตั้งไว้แล้ว โดยตัวเว็บไม่ต้องติดตั้ง dependency:

```sh
node tests/physics.test.cjs
EE_PLAYWRIGHT_PATH=/absolute/path/to/playwright node tests/scene.test.cjs
EE_PLAYWRIGHT_PATH=/absolute/path/to/playwright node tests/browser.test.cjs
EE_PLAYWRIGHT_PATH=/absolute/path/to/playwright node tests/language.test.cjs
```

การทดสอบ 3D ครอบคลุม WebGL จริง การคงสถานะวงจร กล้อง การเลือกขั้วด้วย ray การคลิก/ลาก/ถอดสาย การวางอุปกรณ์ เครื่องมือและใบงานในฉาก ความเสียหาย การจำมุมกล้องและกลับหน้าเดิม การกู้คืน context การสลับภาษา ทัชสกรีน และการกลับไปใช้ 2D เมื่อ WebGL ใช้งานไม่ได้
